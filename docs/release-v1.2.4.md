The in-game menu can no longer leave a game frozen.

## Fixed

- **The in-game menu froze the game when the pad was not read** (an 8BitDo adapter, #11). With no new press for
  10 seconds the menu now closes by itself and the game goes on. The 8BitDo still cannot pick an option in the menu.

## Updating

With the network cable in, START at the update notice. Otherwise copy `launcher.elf` **and** `neutrino/` from the
zip over the ones on your drive.
